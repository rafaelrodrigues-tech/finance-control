# Finance Control

API REST para gerenciamento de despesas pessoais, desenvolvida com C# e ASP.NET Core Web API.

## Tecnologias

- C# / ASP.NET Core Web API
- Entity Framework Core
- PostgreSQL
- FluentValidation

## Funcionalidades

- Cadastro e consulta de despesas
- Busca por ID
- Atualização e exclusão de despesas
- Validação de dados
- Tratamento de exceções

## Objetivo

Projeto pessoal desenvolvido para aprimorar conhecimentos em desenvolvimento back-end com .NET, integração com banco de dados e organização de código.
